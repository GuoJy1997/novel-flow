# 长篇小说抗遗忘核心因果引擎与伏笔总账指南 (Memory Ledger & Foreshadowing)

长篇连载（20 万字至数百万字）最致命的硬伤是**“写到后面忘记前面”**、**“人物状态穿帮”**以及**“绝境突然机械降神”**：
- **记忆遗忘**：第 10 章断臂的配角在第 30 章双手结印；第 15 章抵押的佩剑在第 25 章突然拔出；前卷死透的角色借尸还魂；
- **机械降神**：到了危机死局，主角凭空掏出一个从未铺垫过的神器或外挂解决问题，彻底摧毁读者的期待与代入感。

大语言模型是无状态概率生成器，没有世界状态机。本技能指导流水线**“不靠模型泛化回忆，靠每章状态结构化回写与伏笔全生命周期台账”**。

---

## 一、 核心法则：每章状态回写 (State Writeback) 与极简任务包

> 💡 **工业级抗遗忘铁律**：
> 绝不把整本小说几十万字全部塞进 Prompt 上下文（会引发严重注意力漂移与失真崩溃），而是：
> 1. **每章正文完成后，提取结构化 `CHANGES` 变更声明，回写 15 维事实快照账本与伏笔台账**；
> 2. **下一章起草时，调度器只组装包含本章出场角色最新生理状态、上一章末尾 300 字衔接文本以及本章待推进/回收的伏笔！**

---

## 二、 15 维实时事实快照体系 (The 15-D Fact Snapshot)

系统全局维护 `设定/事实账本/snapshot.json`，涵盖 15 大确定性维度：

| 维度 | 追踪对象 | 字段示例 | 防止的穿帮问题 |
| :--- | :--- | :--- | :--- |
| **1. 角色生理/境界** | 境界等级、伤势残缺、负面状态 | `健康: 左臂骨折包扎, 状态: 轻度虚脱` | 杜绝重伤健步如飞、断臂重生 |
| **2. 角色物理位置** | 当前具体所在建筑/地点/坐标 | `当前所在: 07号监测站地下二层机房` | 杜绝未声明移动的“瞬间传送闪现” |
| **3. 角色外貌特征** | 瞳色、发色、习惯动作、伤疤 | `特征: 右耳缺角, 习惯左手握刀` | 杜绝外貌描写前后矛盾 |
| **4. 物品所有权** | 重要道具、武器、密电盒归属人 | `黑匣子密钥 -> 林巡 (战术包内)` | 杜绝非持有者隔空祭出宝物 |
| **5. 秘密与知情矩阵** | 秘密内容、已获知者集合、获知途径 | `秘密: 避难所内鬼是陈四; 知情者: [主角]` | **严防配角偷看大纲/未卜先知** |
| **6. 伏笔生命周期** | 分级（全书/卷/章）、状态（已埋/发酵/待收） | `ID: omega_clue, 状态: 发酵中, 埋设章: 1` | 杜绝伏笔失踪或突兀机械降神 |
| **7. 剧情冲突线** | 各方矛盾当前阶段（对峙/恶化/爆发） | `主线冲突: 信标污染危机 (处于调查期)` | 杜绝冲突走神跑偏 |
| **8. 角色人际网** | 好感度、仇恨度、隶属信任度 | `陈四对林巡: 表面顺从, 暗藏杀机` | 杜绝仇敌突然推心置腹 |
| **9. 地点环境状态** | 地点封印、损毁程度、出入权限 | `主控闸门: 已被物理熔断, 无法通行` | 杜绝已毁场景照常进出 |
| **10. 势力格局动态** | 门派动乱、势力兼并、首领更迭 | `天剑宗: 戒严封山, 内部夺权` | 杜绝势力背景与情节脱节 |
| **11. 连续时间线** | 故事经过天数、时辰、具体时段 | `第3天 深夜 02:30, 累计经过 52 小时` | 杜绝时序倒流与白天黑夜穿帮 |
| **12. 世界观硬规则** | 物理法则、不可违背铁律 | `硬规则: 凡人未穿防护服入迷雾必死` | 杜绝吃书与破坏战力体系 |
| **13. 誓约契约约束** | 角色之间立下的誓言、违约代价 | `誓约: 三日内归还信标, 违者灵识自焚` | 杜绝角色违约无代价 |
| **14. 倒计时压力源** | 限时任务、核爆倒计时、毒发期限 | `倒计时: 距离反应堆过载自毁还有 2 小时` | 强化紧迫感，杜绝时间感知迟钝 |
| **15. 历史里程碑** | 每章 100 字高密度微摘要链 | `第1章: 林巡抵监测站截获密电并遭遇背刺` | 保持跨卷历史大脉络清晰 |

## 三、 草蛇灰线：伏笔生命周期的四大阶段

高品质小说的核心魅力在于“意料之外，情理之中”的伏笔闭环。每一条重大悬念线索，必须完整经历四大阶段：

```
[第 1 阶段: 播种 (Planting)] ──> [第 2 阶段: 发酵 (Echoing)] ──> [第 3 阶段: 锁紧 (Tightening)] ──> [第 4 阶段: 爆破回收 (Payoff)]
  日常道具/不起眼动作伪装          不经意的异常蜂鸣/侧面印证        危机加剧/生死存亡直指该线索       扣动扳机/前文细节瞬间串联
```

1. **第 1 阶段：播种 (Planting)**：
   - 将关键道具或破绽伪装在日常物理动作中；
   - *范例*：主角在第一章修表时，随手把一枚特殊合金垫片塞进了靴子夹层。
2. **第 2 阶段：发酵与呼应 (Echoing)**：
   - 隔若干章节，通过侧面环境或配角反应给予微弱提示，不引起读者过分警觉；
   - *范例*：第五章过安检闸门时，探测器曾发出过一次短暂的材质误报蜂鸣。
3. **第 3 阶段：锁紧与递进 (Tightening)**：
   - 矛盾升级，该线索的存在开始与主角的生死直接相关；
   - *范例*：第九章主角被剥夺所有武器锁入牢房，电子门锁恰好需要特定抗性的导电介质。
4. **第 4 阶段：爆破回收 (Payoff)**：
   - 扣动扳机，伏笔彻底兑现，完成逻辑闭环；
   - *范例*：第十章主角抽出靴底垫片短路门禁，读者恍然大悟：“原来第一章埋下的东西在这里用上了！”

## 四、 拒绝“机械降神 (Deus Ex Machina)”的两大铁律

1. **破局工具必须前置登场**：
   - 主角在绝境中使用的绝招、道具、隐藏身份、人脉或关键情报，**必须在至少前三章**就已经被自然提及或合理解释过来源；
2. **代价守恒法则**：
   - 任何强力伏笔的回收破局，不能带来无痛的绝对胜利，必须伴随不可逆的代价（如核心武器报废、同伴重伤牺牲、关键底牌彻底暴露给反派）。

## 五、 12 类强制变更声明规范 (CHANGES Protocol)

每一章的正文写完后，提取并输出标准的 CHANGES 结构块：

```json
CHANGES: {
  "chapter": 11,
  "character_updates": [
    {"id": "lin_xun", "health_status": "左肩中弹包扎", "realm_or_level": "资深领航员"}
  ],
  "character_moves": [
    {"id": "lin_xun", "from": "天穹号舰桥", "to": "下层逃生舱隔离走廊"}
  ],
  "item_transfers": [
    {"item": "黑匣子密钥", "from": "死者陈四", "to": "lin_xun"}
  ],
  "secret_reveals": [
    {
      "id": "beacon_betrayal",
      "learned_by": ["lin_xun"],
      "method": "从陈四随身日记中读取到叛徒暗号"
    }
  ],
  "clue_actions": [
    {"id": "signal_echo", "action": "developing", "notes": "回声中出现熟悉的求救代码"}
  ],
  "timeline_advance": {
    "hours": 1.5,
    "time_of_day": "深夜",
    "day": 1
  }
}
```

在流水线执行或审查时，因果守卫门禁将基于此账本核验：
- **生理门禁**：死亡角色严禁再行动，骨折重伤角色严禁剧烈动作；
- **时空门禁**：严防无位移说明的瞬间闪现；
- **物品门禁**：角色只能使用当前持有的物品；
- **反机械降神门禁**：危急关头的解局关键必须能在前期伏笔账本中找到 `planted` 记录！
