# 通用副本法则与生存机制架构指南 (Dungeon Physics & Survival Mechanics)

在任何优秀的智斗、悬疑或冒险小说中，最扣人心弦的副本/封闭舞台从来不是“主角换了个地图打数值更高的怪”，而是**角色进入了一个具备严密自洽性、反常理物理/因果规律、并且违规即抹杀的独立法则系统**。

如果一个技能只能套用在某一本特定历史小说上，那它不是技能，只是特定设定的复读机。
本技能提供一套**完全抽象、可自由迁移至【规则怪谈/无限流】、【硬核科幻/太空惊悚】、【修真宗门/上古秘境】、【现代商战/致命密室】等任意题材**的通用法则构架引擎。

---

## 一、 通用三层法则模型 (The 3-Tier Axiomatic Framework)

无论什么题材，任何高智商封闭副本的底层机制都由以下三层数学/因果公理构成：

```
┌─────────────────────────────────────────────────────────────┐
│  第三层：生门兑现契约 (Win Condition & Exit Contract)        │
│  （通关不是杀光敌人，而是因果闭环 / 法则对冲 / 认知破壁）    │
├─────────────────────────────────────────────────────────────┤
│  第二层：负向致死判定律 (Negative Lethal Trigger)           │
│  （严格的行为-状态因果抹杀，无视实力等级与主角光环）          │
├─────────────────────────────────────────────────────────────┤
│  第一层：表象环境律与知觉污染 (Distortion & Perception Trap)  │
│  （物理常数异化、时空畸变、以及原住民深信不疑的伪常识）      │
└─────────────────────────────────────────────────────────────┘
```

---

### 1. 第一层：表象环境律与知觉污染 (Distortion & Perception Trap)
- **核心逻辑**：副本的运行机制不是写在公告栏上的真理，而是**被扭曲的现象**与**原住民的认知偏差**。
- **四大异化维度（跨题材通用）**：
  1. **度量衡异变（时空与坐标）**：
     - *科幻*：引力波透镜导致时间膨胀，外界一秒，内部半小时；
     - *玄幻*：须弥芥子与九宫八卦错位，直行三十里回到原地；
     - *怪谈*：楼梯层数随心跳频率增减，电梯永远到不了第 4 层。
  2. **感官与信息不对称（知觉衰减）**：
     - 声音传导延迟、视网膜残影投射、光学伪装；
  3. **原住民的【伪常识污染】（Cognitive Contamination）**：
     - **极关键的设计**：副本内的 NPC 会极其真诚地传授主角一套“生存守则”，但这套守则本身就是致死陷阱或时代迷障（如：某星际废船船员坚信向中央反应堆祈祷可以免受辐射，实则是致幻神经毒气；修仙古修坚信吞服血丹可避雷劫，实则是把肉身改造成傀儡）。

---

### 2. 第二层：负向致死判定律 (Negative Lethal Trigger)
- **铁律**：**严禁将危机写成“怪物攻高血厚”，必须写成【严格的条件判定式】**！
- **判断标准**：如果把怪物换成不可见的物理规则，剧情依然完全成立，才是合格的高智商致死律。
- **四大致死触发判定范式**：
  1. **【行为-观测关联律】（The Observation-Action Paradox）**：
     - *逻辑*：当处于状态 A（如移动实体/发出声音/使用灵力）时，若被判定源 B（活人视网膜/红外雷达/声波共振器）捕获，立即触发因果抹杀。
  2. **【状态对称律 / 同质化侵蚀】（Symmetry Erosion）**：
     - *逻辑*：进入者如果在行为、心率、呼吸节奏上连续 N 次与死者/污染源完全同频，系统判定其已死亡并强制剥夺物理实体。
  3. **【禁言与认知触发律】（Semantic Trigger）**：
     - *逻辑*：在特定空间内，只要说出特定语义、或逻辑推导达到特定结论，就会引来环境规则的即时清洗。
  4. **【倒计时资源枯竭律】（Resource Decay Clock）**：
     - *逻辑*：生命维持系统氧气倒计时、神魂在阴煞之气下的半衰期、理智值（SAN值）与暴露时长的刚性负相关。

---

### 3. 第三层：生门兑现契约 (Win Condition & Exit Contract)
- **铁律**：**生门的开启，绝不能是“暴力碾压或者大招爆发”，必须是“逻辑破解与法则对冲”**！
- **三大破局逻辑模型**：
  1. **法则对冲（The Rule Collision / 卡系统 Bug）**：
     - 两个看似绝对无解的死局规则，当且仅当满足某个边缘条件时，会产生逻辑互斥，从而撕开一条 10 秒钟的“法则盲区狭缝”；
     - *案例范式*：规则甲说“黑暗中必有死神收割”，规则乙说“强光照射处空间崩解”。主角通过制造高频频闪，让两套防御机制同时报错重启，借机穿过警戒线。
  2. **因果溯源与信物退相干（Causal Decoupling）**：
     - 导致整片区域异变的核心奇点是一个“时空/因果错位的锚点”，将其放回最初的原点，异变自然平息；
  3. **定义颠覆与跳出棋盘（Meta-Redefinition）**：
     - 破解者发现“胜负判定机制”本身的判定标准存在漏洞，通过改变自身的身份标识或重新定义比赛边界通关。

## 二、 破局剪刀前置法则 (The Loophole Conservation Law)

向世界顶尖智斗作品学习的终极心法：**绝对拒绝机械降神（Anti-Deus Ex Machina）**。

```
[开局 0% ~ 20%] ──> 剪刀以“无害日用品/无意识习惯/背景说明”登场（读者与角色均未察觉）
        │
[中盘 50% ~ 70%] ──> 局势彻底绝望，常规手段全部失效，发现两条规则相互咬死
        │
[终盘 80% ~ 90%] ──> 灵光一现，发现开局那个不起眼的道具恰好是唯一的逻辑解（恍然大悟）
```

- **三要素检验法则**：
  1. **物理存在性**：该工具/情报必须在主角踏入绝境前就已经在场，不可半途凭空捡到；
  2. **认知反差性**：登场时必须具备合情合理的伪装用途（如：一把生锈的钥匙、一段随口抱怨的杂谈、一张写错日期的账单）；
  3. **代价守恒性**：使用剪刀破局不能是无痛的，必须伴随不可逆的代价（重要防具彻底碎裂、同伴重伤残疾、或消耗掉全书仅有一份的战略资源）。
