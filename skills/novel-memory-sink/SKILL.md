# 章节状态沉淀与长程记忆闭环指南 (Memory Sink)

长篇小说的终极壁垒是“写到第 80 章时，依然精准记得第 3 章埋下的那把钥匙在谁的手里”。
本技能专用于接在 `author_accept`（作者放行）节点之后，充当**小说事实账本登记官**。

---

## 一、 沉淀的三大实体台账

章节入库后，自动解析并写回以下三份轻量级 Markdown / JSON 档案：

### 1. 事实总账与时间线 (`workflow/canon_facts.md`)
记录本章新确立的不可逆事实：
```markdown
- [第 1 章] 远望号偏航 1.2 光年，捕获天穹号深空信标；
- [第 1 章] 天穹号黑匣子第一音轨证实五年前录入了陆巡的声音；
- [第 1 章] 信标残骸已物理撞入远望号一号减压舱，外层防爆闸门破损。
```

### 2. 人物动态状态快照 (`workflow/characters_state.json`)
记录角色当下的物理位置、知情变化与物资变更：
```json
{
  "陆巡": {
    "location": "远望号舰桥操舵台",
    "injury": "后颈神经芯片轻微过载发热",
    "known_secrets": ["天穹号黑匣子里有自己的录音", "林朔在隐瞒军方撤离指令"]
  },
  "林朔": {
    "location": "远望号舰桥配电箱前",
    "status": "持枪警戒状态",
    "mental": "对陆巡的真正身份产生剧烈动摇"
  }
}
```

### 3. 伏笔与悬念台账 (`workflow/clues_ledger.md`)
跟踪线索生命周期：
```markdown
- [CLUE-001: 陆巡的五年前录音]
  - 首次出现：第 1 章
  - 核心疑点：陆巡档案中未曾登上天穹号，为何黑匣子有其临终录音？
  - 当前状态：已播下 (Seeded)
  - 拟回收卷：第一卷末（第 12 章）
```

---

## 二、 记忆提取原则

1. **只记增量事实，不记废话对话**：不记录“林朔问了一句话，陆巡回答了一句”，只记录“林朔知晓了录音的存在”；
2. **状态原子递进**：人物一旦受重伤或丢失武器，其状态字段直接变更，下章写作直接读取此状态，防止“上一章骨折、下一章健步如飞”的低级穿帮。
