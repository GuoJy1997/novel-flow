# 五感具象白描与具身化指南 (Sensory Grounding)

AI 生成小说最大的痛点是“悬浮空洞”——频繁使用大而无当的副词与抽象概念（“恐惧极了”、“愤怒到了极点”、“场面无比震撼”），但读者感受不到一丝真实物理刺激。

本技能用于为 `deai_polish`（去 AI 味润色）与 `draft_chapter`（正文起草）节点提供**五感具象置换武器库**。

---

## 一、 抽象情绪向生理应激的精确降维

绝不允许直接写出情绪名词，必须将其翻译为人类身体的生理与神经反射：

| 抽象情绪 (AI 常见写法) | 具身化生理反应 (优质白描) |
| :--- | :--- |
| **他感到极度恐惧** | 喉头泛起干呕的酸苦，后颈汗毛根根立起，下意识收紧脚趾扣住靴底钢板。 |
| **他怒火中烧** | 太阳穴的青筋突突跳动，牙关咬得发酸，握拳时指甲深深陷进掌心肉里。 |
| **他陷入了极度悲伤** | 胸腔像被塞进一块浸满冷水的粗麻布，沉重得透不过气，眼球干涩发胀，视线边缘泛黑。 |
| **他感到非常紧张** | 呼吸下意识压低放浅，舌根发干发苦，能听见自己耳膜里剧烈泵血的轰鸣。 |
| **两人之间剑拔弩张** | 空气冷得像凝固的铅块。谁都没有说话，只有两柄出鞘短刀在冷光灯下微不可察地颤动。 |

## 二、 五感环境锚定法 (The 5-Sense Anchors)

每个重点场景必须至少触发以下 3 种以上的物理锚点：

1. **触觉与温度 (Touch & Temp)**：
   - 物体的材质与冷热：结霜的合金扶手、粗粝的麻绳勒痕、浸透冷汗粘在后背的衬衣、发烫过载的电线胶皮。
2. **气味与味觉 (Smell & Taste)**：
   - 环境的生化信息：电弧击穿空气后留下的刺鼻臭氧味、陈年舱室里的机油陈腐味、嘴唇咬破后的铁锈血腥味。
3. **声响频段 (Auditory Clues)**：
   - 拒绝笼统的“警报尖叫”，细化到分贝与材质反馈：低频的次声波共振让胃部泛酸、高跟鞋踏在镂空格栅上的脆响、风声撕扯帆布的裂帛声。
4. **光影与视野 (Light & Sight)**：
   - 避免无意义的“灯火通明”，关注光源死角：频闪的红光在人脸上投下断续的阴影、护目镜上的冷凝水雾折射出彩虹光晕。

## 三、 白描改写前后实战范例

- **AI 原句**：
  > 整个指挥室陷入了恐慌，大家看着大屏幕上的红色倒计时，内心无比煎熬，谁也不知道接下来会发生什么可怕的事情。
- **具象白描重构**：
  > 通讯台前没人说话。主控屏上的鲜红读秒跳到【00:14】，红光每隔一秒扫过林朔苍白的面颊。通风管道吹出带着焦糊味的冷风，角落里一位年轻技工的右手抖得厉害，扳手失手砸在钢制甲板上，发出一声令人心悸的脆响。
